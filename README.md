# 🔑 Python Password Generator

A simple Password Generator developed using Python that creates secure and random passwords.

## Features

- Generate random passwords
- User can choose the password length
- Includes uppercase and lowercase letters
- Includes numbers
- Includes special characters

## Technologies Used

- Python
- random module
- string module

## How to Run

```bash
python password.py
```
